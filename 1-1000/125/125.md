# 一个注意的问题
在题目描述中有一个说明需要处理，“并移除所有非字母数字字符之后，短语正着读和反着读都一样”<br>
这句话直觉上来说，我会考虑先清理字符串，但是手动遍历和清理字符串其实是非常垃圾的行为
## 这个要求其实是让你使用两个指针寻找每一组符合条件的字符
所以可以使用双指针从左右分别开始遍历，使用利用内置的 isalnum()（判断是否为字母或数字）和 lower()，避免了手动计算 ASCII 码。
## 假如真的有人想要去除这些信息.....
这里还有几个可以选择<br>  
```python
def clean_string(s: str) -> str:
    # 过滤出字母和数字，拼接成新字符串，最后统一转小写
    clean_s = "".join(filter(str.isalnum, s)).lower()
    
    # 判断回文只需将其反转比较即可
    return clean_s == clean_s[::-1]
```
或者是推导
```python
def isPalindrome(s: str) -> bool:
    # 利用推导式提取并转换
    clean_s = [c.lower() for c in s if c.isalnum()]
    return clean_s == clean_s[::-1]
```
或者是正则表达式
```python
import re

def isPalindrome(s: str) -> bool:
    # 匹配所有非字母数字的字符并替换为空字符串
    clean_s = re.sub(r'[^a-zA-Z0-9]', '', s).lower()
    return clean_s == clean_s[::-1]
```
## 注意python 的语法
使用not 而非！ 其次使用lower()，是等于调用函数，注意不是调用属性
